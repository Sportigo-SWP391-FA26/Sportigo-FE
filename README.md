# Sport Center Frontend

React + TypeScript + Vite frontend cho hệ thống quản lý trung tâm thể thao.

## Khởi chạy

```bash
copy .env.example .env
npm install
npm run dev
```

## Kiểm tra

```bash
npm run lint
npm test
npm run build
```

Các module tiếp theo nên đặt theo nghiệp vụ trong `src/features`, ví dụ `members`, `classes`, `subscriptions`, `workout-plans` và `payments`.

Xem [ARCHITECTURE.md](./ARCHITECTURE.md) để biết cấu trúc thư mục và quy tắc phụ thuộc.
